# FramedLocal

A private, local-first iPhone camera and photo-editing project.

The FramedLocal project site lives in [`site/`](site/) and is deployed to GitHub Pages at [`https://mithundb.github.io/FramedLocal/`](https://mithundb.github.io/FramedLocal/) when Pages is available for this private repository. Its interactive preview uses a bundled sample illustration and never opens the visitor's camera.

Start with [docs/FRAMED_LOCAL_CODEX_GOAL.md](docs/FRAMED_LOCAL_CODEX_GOAL.md), then keep [docs/PROJECT_STATUS.md](docs/PROJECT_STATUS.md) current after each meaningful change.
