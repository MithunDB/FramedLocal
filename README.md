# FramedLocal

A local-first iPhone camera and photo-editing project, built to keep photo processing on-device.

The FramedLocal project site lives in [`site/`](site/) and is deployed to [GitHub Pages](https://mithundb.github.io/FramedLocal/). Its interactive preview uses a bundled sample illustration and never opens the visitor's camera.

Start with [docs/FRAMED_LOCAL_CODEX_GOAL.md](docs/FRAMED_LOCAL_CODEX_GOAL.md), then keep [docs/PROJECT_STATUS.md](docs/PROJECT_STATUS.md) current after each meaningful change.
